Comment marche la galerie de tableauxHow the picture gallery works

Chaque tableau de la galerie est une zone de type « image » posée sur un mur du bâtiment 3D. La page affiche, à cet endroit, un plan plat qui montre une image prise dans le dossier medias. Pour changer un tableau, il suffit de remplacer le fichier image : rien d'autre à modifier.

1. Remplacer ou ajouter une image

  • Les images sont dans galerie/medias/. Le tableau n° 7 correspond au fichier 7.jpg.
  • Remplacez le fichier par une autre image du même nom : elle apparaît à la prochaine visite, sans vider le cache du navigateur.
  • Formats essayés, dans cet ordre : jpg, jpeg, png, webp, gif, avif.
  • Écrivez les noms en minuscules (2.jpg, pas 2.JPG) : sous Windows la casse ne compte pas, mais sur la plupart des hébergements 2.jpg et 2.JPG sont deux fichiers différents, et le tableau resterait vide.
  • Quand la hauteur de la zone vaut 0 (cas de presque tous les tableaux fournis), la page garde la proportion de l'image : une image large donne un tableau large, sans déformation.

2. Les légendes

Une légende s'affiche sous le tableau. Deux façons de la donner :

MéthodeExempleRésultat
Dans le nom du fichier : le texte après le premier tiret8-Amusement, Gauguin, 1892.jpg« Amusement, Gauguin, 1892 » (un _ devient une espace)
Un fichier texte du même nom (UTF-8) : sa première ligne non vide9.txt contenant « Une odalisque »« Une odalisque » (remplace la légende du nom de fichier)

Le fichier .txt porte le même nom que l'image, sans l'extension : pour 9.jpg, c'est 9.txt, rangé à côté de l'image dans medias/. Sans légende, aucune bande de texte n'apparaît.

3. Ce qui fixe le nombre et la place des tableaux

Les zones (emplacement sur le mur, orientation, largeur w, hauteur h) sont enregistrées dans galerie/galerie.zones.json. Avec h = 0, la hauteur suit la proportion de l'image. Déplacer, ajouter ou supprimer un tableau se fait dans l'éditeur de zones du viewer de Web_3d (glb-viewer.html, outil séparé), qui écrit ce fichier : la page exportée de la galerie, elle, ne sert qu'à visiter.

Tant que vous ne changez que le contenu de medias/, aucun outil n'est nécessaire.

4. Héberger la galerie

  • Copiez tout le dossier sur un hébergement web (GitHub Pages, un serveur web, un hébergement mutualisé). Il n'y a rien à installer sur le serveur.
  • La galerie doit être sur un site web (adresse commençant par http:// ou https://). Si vous double-cliquez sur index.html depuis votre disque (adresse commençant par file://), la galerie ne s'ouvre pas : la page n'affiche qu'un message qui demande d'être servie en http ou https.
  • Pour essayer chez soi : lancer un petit serveur dans le dossier (par exemple python -m http.server), puis ouvrir http://localhost:8000/.
Les dimensions des images ne sont pas limitées par la page, mais chaque visiteur les télécharge : une image légère se charge plus vite. À titre de repère, la galerie de démonstration pèse environ 5 Mo pour 31 images. Ce n'est pas une limite mesurée.

Each picture in the gallery is an “image” zone placed on a wall of the 3D building. At that spot the page draws a flat plane showing an image taken from the medias folder. To change a picture, just replace the image file: nothing else needs editing.

1. Replace or add an image

  • Images live in galerie/medias/. Picture no. 7 is the file 7.jpg.
  • Replace the file with another image of the same name: it shows up on the next visit, without clearing the browser cache.
  • Formats tried, in this order: jpg, jpeg, png, webp, gif, avif.
  • Use lowercase file names (2.jpg, not 2.JPG): Windows ignores case, but on most web hosts 2.jpg and 2.JPG are two different files, and the picture would stay empty.
  • When the zone's height is 0 (almost all the supplied pictures), the page keeps the image's proportions: a wide image gives a wide picture, undistorted.

2. Captions

A caption is shown under the picture. Two ways to provide it:

MethodExampleResult
In the file name: the text after the first hyphen8-Amusement, Gauguin, 1892.jpg“Amusement, Gauguin, 1892” (a _ becomes a space)
A text file of the same name (UTF-8): its first non-empty line9.txt containing “An Odalisque”“An Odalisque” (replaces the caption from the file name)

The .txt file has the same name as the image, without the extension: for 9.jpg it is 9.txt, stored next to the image in medias/. With no caption, no text strip is shown.

3. What fixes the number and position of the pictures

The zones (position on the wall, orientation, width w, height h) are stored in galerie/galerie.zones.json. With h = 0 the height follows the image's proportions. Moving, adding or removing a picture is done in the zone editor of the Web_3d viewer (glb-viewer.html, a separate tool), which writes that file: the exported gallery page itself is for visiting only.

As long as you only change the contents of medias/, no tool is needed.

4. Hosting the gallery

  • Copy the whole folder to a web host (GitHub Pages, a web server, shared hosting). Nothing to install on the server.
  • The gallery must be on a website (address starting with http:// or https://). If you double-click index.html from your disk (address starting with file://), the gallery does not open: the page only shows a message asking to be served over http or https.
  • To try it at home: start a small server in the folder (for example python -m http.server), then open http://localhost:8000/.
The page does not limit image dimensions, but every visitor downloads them: a lighter image loads faster. As a rough guide, the demo gallery weighs about 5 MB for 31 images. That is not a measured limit.
